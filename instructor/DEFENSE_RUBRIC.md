# Final Defense Rubric

| Criterion | Excellent | Good | Weak |
|---|---|---|---|
| System | Clear architecture/dependencies | Mostly clear | Tool list instead of system |
| Risks | Prioritized by impact | Risks listed | Tests disguised as risks |
| Strategy | Traceable to risks | Partial traceability | Random test collection |
| Evidence | Supports claims | Some useful evidence | Screenshots without context |
| Scope | Explicit limitations | Some limitations | Claims simulator proves everything |
| Decision | Evidence-based | Reasonable | Based on pass percentage |
| Defense | Concise engineering story | Understandable | Tool/technology recital |
